# Anomaly Detection for Network Security Using Cloud

Real-time ML system to detect network threats (DDoS, Port Scanning, 
Brute Force) using AWS and Azure cloud infrastructure.

## Results
- Detection Accuracy: 99.23455432
- Dataset: 100
- Models: Random Forest, Isolation Forest, Autoencoder

## Tech Stack
- Python, Scikit-learn, Pandas, NumPy
- AWS SageMaker, Azure Monitor
- Power BI, Git, GitHub

## Project Structure
- Dataset/ — network traffic data
- models/ — trained ML models
- cloud dataset.csv — processed data
- features.csv — feature engineered data
- metrics.json — model performance metrics
- preprocessed.csv — cleaned dataset

## How to Run
1. Install requirements: pip install -r Requirements.txt
2. Run the server: runserver.bat
